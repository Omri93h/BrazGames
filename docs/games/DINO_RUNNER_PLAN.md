# Dino / Escape From Be'er Sheva Plan

Status: Not implemented yet.

## Concept

A local browser runner where Dor runs away from Be'er Sheva.

Visual ideas:

- Road/desert/Be'er Sheva theme.
- A sign saying something like "צאתכם לשלום באר שבע".
- Obstacles related to Be'er Sheva, desert life, or local jokes.

## Desired Player Count

- Two-player version desired if feasible.
- Single-player fallback only if approved later.

## Desired Controls

Possible controls:

- Player 1: keyboard key such as `W`, `Space`, or `A/D` depending on movement.
- Player 2: arrow keys or another dedicated key.
- Gamepad support only if simple and tested.

## Desired Screen Layout

Options to decide later:

- Split screen.
- Two differently colored characters on the same screen.

The split orientation is not final.

## Asset Replacement Ideas

- Dor runner character.
- Be'er Sheva road/desert background.
- Exit sign image or text treatment.
- Local-joke obstacles.
- Funny fail screen.

Use placeholders until real assets are approved.

## Sound Replacement Ideas

- Jump.
- Land.
- Collect.
- Hit obstacle.
- New high score.
- Game over.

## Scoring / Win Condition

Possible scoring:

- Distance survived.
- Collectible count.
- Last player standing.
- Best score after a fixed number of rounds.

The party version should make the winner obvious.

## Known Risks

- Two-player runner mechanics can be awkward if players collide or share obstacles.
- Split-screen implementation may be more complex than a same-screen race.
- Timing must feel responsive on the party laptop/projector.
- Source repo/license must be checked before use.

## Implementation Notes For Later

- Proposed URL: `http://localhost:3003`.
- Do not implement before Memory and Fishy / Submarine Survival are approved.
- Keep the first version minimal and playable.
