# Super Brazio Plan

Status: Not implemented yet.

## Concept

Super Brazio is a Mario-style local platformer concept.

Story:

- Dor must reach Princess Daniel, his future wife.
- Daniel waits at the end with a Golden Visa / Green Card.
- The level should feel hard but possible.
- Checkpoints should help the run feel challenging without becoming frustrating.

## Desired Player Count

- Single-player first is acceptable.
- Two-player should only be considered if explicitly approved later.

## Desired Controls

Likely controls:

- Keyboard movement.
- Jump.
- Optional run/action key.

Exact controls depend on the selected base implementation.

## Desired Screen Layout

- Side-scrolling platformer.
- Clear start, checkpoints, obstacles, collectibles, and end goal.
- Projector-friendly scale.
- Final goal area with Princess Daniel and the Golden Visa / Green Card.

## Asset Replacement Ideas

- Main character: Dor.
- Princess/end goal: Daniel with Golden Visa / Green Card.
- Powerups/mushrooms: Amazon logo placeholders, because Dor works with Amazon.
- Collectibles: dollars, visas, papers, green cards.
- Enemies/obstacles: immigration, IRS, rent, visa denied, bureaucracy.
- Checkpoints: visa desk, embassy stamp, or similar local placeholder.

Use placeholder assets only. Do not use copyrighted Nintendo or Mario assets in the repo.

## Sound Replacement Ideas

- Jump.
- Collect.
- Powerup.
- Checkpoint.
- Damage.
- Visa denied.
- Level complete.
- Game over.

## Scoring / Win Condition

Possible scoring:

- Collect dollars, visas, or papers.
- Reach Princess Daniel at the end.
- Bonus for time remaining or collectibles.

Win condition:

- Dor reaches Princess Daniel and the Golden Visa / Green Card.

## Known Risks

- Platformers can become large and time-consuming.
- Source repo and license must be verified before use.
- Asset replacement can be more involved than simpler games.
- Avoid copyrighted public assets; use placeholders in the repo.
- Difficulty must be tuned so the level is hard but possible.

## Implementation Notes For Later

- Proposed URL: `http://localhost:3004`.
- Verify license and local run instructions before using a source repo.
- Keep scope small: one funny level is better than an unfinished complex platformer.
