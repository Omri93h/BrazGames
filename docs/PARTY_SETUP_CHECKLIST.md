# Party Setup Checklist

Use this checklist before the party.

## Hardware

- Laptops charged.
- Laptop chargers packed.
- Projectors packed.
- Projector power cables packed.
- HDMI/USB-C adapters packed.
- Speakers or audio output tested.
- Controllers, keyboards, and mice packed.
- Spare batteries or charging cables for controllers.

## Localhost Setup

- If using the launcher, the root portal opens at `http://localhost:3000`.
- Each approved game starts on its documented localhost port.
- Ports do not conflict.
- Browser opens the correct URL.
- Fullscreen mode works.
- Restart flow is clear.
- Offline mode is tested with Wi-Fi disabled.

## Display

- Connect the actual TV/projector before opening the game tabs.
- Use browser fullscreen on the party display.
- Set browser zoom to 100%.
- Confirm the OS display is using the intended mirror/extended-screen mode.
- Projector/TV resolution tested after connection.
- Game is readable from the expected distance.
- Split-screen layouts fit the projector.
- No important UI is cut off.
- No start-screen fighter, player card, score panel, or result modal is clipped.
- For moving games, play at least 30 seconds on the connected display to check that speed/difficulty still feels right.

## Display QA Matrix

Use the real party display first. If time allows, also spot-check these common sizes:

- 1920x1080 fullscreen.
- 1366x768 fullscreen.
- 1280x720 fullscreen.
- 1024x768 fullscreen, if an older projector may be used.

If a game looks wrong only on one display, do not rewrite gameplay immediately. First verify fullscreen, 100% zoom, and the browser tab's actual viewport size.

## Audio

- Volume is tested.
- Sound effects are not too loud.
- Mute or volume controls are understood.
- Audio works after browser reload.

## Controls

- Player 1 controls tested.
- Player 2 controls tested.
- Keyboard ghosting checked for two-player games.
- Gamepads tested if used.
- Mouse behavior tested if used.

## Game Flow

- Start game.
- From the portal, click each game card and confirm the intended game opens from its clean start screen.
- Finish round.
- Restart round.
- Return to menu or reload page.
- Confirm winner or score display.
- Confirm placeholder or real approved assets display correctly.
