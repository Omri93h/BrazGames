# Sound Replacement Guide

Sound should be funny, short, and reliable.

Use local audio files only. Do not depend on external audio URLs at runtime.

## Recommended Formats

- `MP3` for compact sound effects.
- `WAV` for simple short clips when quality or compatibility is useful.

## Clip Length

Most party sound effects should be short:

- Ideal length: `0.5` to `1.5` seconds.
- Avoid long clips that block or overlap gameplay too much.
- Normalize volume before the party so one clip is not painfully louder than the others.

## Common Sound Categories

Games can define sounds such as:

- `hit`
- `miss`
- `win`
- `lose`
- `start`
- `powerup`
- `game-over`

Use placeholders until real audio is explicitly provided and approved.

## Replacement Rules

Each game should document:

- Sound file location.
- Expected filenames or config keys.
- Supported formats.
- How to mute or reduce volume.
- Manual audio test steps.
