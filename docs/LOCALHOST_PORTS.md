# Localhost Ports

Each approved game should be served from its own local port. Ports can change later if needed, but every game must document its final run command and URL.

| Game | Proposed URL | Status |
| --- | --- | --- |
| Memory Game | `http://localhost:3001` | Reserved |
| Fishy / Submarine Survival | `http://localhost:3002` | Reserved |
| Dino / Escape From Be'er Sheva | `http://localhost:3003` | Reserved |
| Super Brazio | `http://localhost:3004` | Reserved |

Run instruction requirements for each game:

- Exact install/setup steps, if any.
- Exact command to start the local server.
- Exact localhost URL.
- Offline runtime check.
- Restart instructions.

Party rule: before the event, open every approved game once on the actual laptop/projector setup and verify the documented URL works.
