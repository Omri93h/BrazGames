# Dino Background Images

Background images for the Be'er Sheva runner go here.

Examples:

- road
- desert
- Be'er Sheva sign
- skyline or local joke background

Use local WebP/JPG/PNG files only.

Opening-screen image:

- The current opening screen uses local CSS placeholder layers from `games/dino/style.css`.
- If replacing it with a real local image later, put that image here, update `--start-bg-image`, and bump the stylesheet cache-busting query string in `games/dino/index.html`.
