# Background Images

Put local background images here.

Expected filenames:

```text
dor_army.jpeg
underwater-background.webp
```

Recommended:

- Use WebP or JPG for backgrounds.
- Keep files lightweight for the party laptops.
- The start image should work well in a wide rectangular frame.
- The underwater background should remain readable behind moving submarines and enemies.

If these files are missing, the game uses the built-in CSS/Canvas placeholder backgrounds.
