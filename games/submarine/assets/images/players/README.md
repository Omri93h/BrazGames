# Player Submarine Images

Put player submarine sprites here.

Expected filenames:

```text
dor_face.webp
submarine-blue.png
submarine-blue-damaged.png
submarine-red.png
submarine-red-damaged.png
```

Use transparent PNG or WebP if possible.

`dor_face.webp` is a small transparent face cutout drawn inside the rear of both submarines. The selected character's face-card portrait is drawn inside the front of that team's submarine.

If damaged images are missing, the game uses the normal image and draws a simple damage overlay on top.
