# Memory Game Images

This folder is for real Memory Game images added later.

Do not add private photos unless they are explicitly provided and approved.

Recommended image naming:

- `dor-01.webp`
- `dor-02.webp`
- `friends-01.webp`
- `group-joke-01.webp`
- `usa-01.webp`
- `visa-01.webp`
- `wedding-01.webp`
- `party-01.webp`

Recommended format:

- Use `WebP` or `JPG` for photos.
- Use `PNG` when transparency is needed.
- Crop images to a square shape when possible.
- Keep files lightweight for reliable party runtime.

The MVP currently uses built-in text placeholders from `game.js`. Later, each card identity can point to a local image path such as:

```js
image: "assets/images/dor-01.webp"
```
